The **Repository view** is your file system for content. Browse folders, see versions, and run actions.

## Tips
- Use a clear folder taxonomy.
- Filter and search to find content fast.
- Right-click for context actions.

## Takeaway
A tidy repository with a consistent structure makes everything else in AEM Guides easier.
