Learning a few editor shortcuts makes daily authoring noticeably faster.

## Worth memorizing
- Insert element and insert table.
- Bold, italic, and inline code.
- Save and toggle views.

## Takeaway
Pick three shortcuts you'd use hourly and learn them this week. Speed compounds.
