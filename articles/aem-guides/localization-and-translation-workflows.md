AEM Guides has built-in **translation** support that tracks source and target languages topic by topic.

## The flow
1. Select content and target languages.
2. Send for human or machine translation.
3. Review and manage returned translations.

## Takeaway
Because DITA is modular, only changed topics need re-translation. Saving real time and cost.
