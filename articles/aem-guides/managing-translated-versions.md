Once translated, content must stay aligned with the source as it evolves.

## Keys to success
- Track which topics changed since last translation.
- Re-translate only what's needed.
- Validate that maps resolve in every language.

## Takeaway
Sync, don't restart. Modular translation means small, targeted updates instead of full re-dos.
