**Keyref** points to a *key* defined in a map instead of a fixed file path. That indirection makes content portable across deliverables.

## Why it matters
- Swap a key's definition per map to reuse the same topic in different contexts.
- Manage product names, URLs, and links centrally.
- Avoid broken links when files move.

## Takeaway
Use keyref when the same topic must behave differently across outputs. It's reuse with flexibility built in.
