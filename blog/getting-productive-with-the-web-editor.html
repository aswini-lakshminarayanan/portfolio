Getting productive with the Web Editor

AEM GuidesAuthoring

The Web Editor is where most authoring happens. No desktop tool required.

Handy features

  • WYSIWYG and XML views to switch between writing and markup.
  • Inline validation so you catch structure errors early.
  • Quick insert for elements, tables, and references.
  • Autosave and versioning to protect your work.

Takeaway

Learn a few toolbar shortcuts and the Web Editor becomes as fast as any desktop authoring tool.
