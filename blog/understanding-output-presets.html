Understanding output presets

AEM GuidesPublishing

An output preset stores the format, template, conditions, and destination for a publish job so anyone can reproduce it.

What a preset holds

  • Output type (PDF, HTML5, and more).
  • Template and layout choices.
  • DITAVAL conditions.
  • Publishing destination.

Takeaway

Configure presets once. After that, consistent publishing is a single click for everyone.
