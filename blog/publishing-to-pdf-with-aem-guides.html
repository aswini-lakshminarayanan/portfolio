Publishing to PDF with AEM Guides

AEM GuidesPublishing

AEM Guides can publish a map straight to PDF using an output preset.

Steps

  1. Open the map and choose Generate Output.
  2. Select a PDF preset.
  3. Pick a template and any conditions (DITAVAL).
  4. Run it and download the result.

Takeaway

Once a PDF preset is configured, publishing becomes a repeatable, one-click task for the whole team.
