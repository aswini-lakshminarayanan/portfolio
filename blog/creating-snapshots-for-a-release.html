Creating snapshots for a release

AEM GuidesGovernance

Snapshots (via baselines and labels) freeze content so a release stays reproducible.

Practical steps

  • Label the approved versions.
  • Create a baseline from those labels.
  • Publish outputs from the baseline.

Takeaway

A disciplined snapshot process means you can always rebuild exactly what you shipped.
