Creating your first DITA topic

AEM GuidesAuthoring

Topics are where your actual content lives. In AEM Guides you create them right in the browser.

Steps

  1. Create a new topic and pick a type (concept, task, or reference).
  2. Give it a clear title and short description.
  3. Write your content in the Web Editor using the toolbar for structure.
  4. Save; the editor keeps the underlying XML valid for you.

Takeaway

Let the editor handle the XML. Focus on writing one clear idea per topic.
