Managing images and media references

AEM GuidesAuthoring

Images in DITA are referenced, not embedded. AEM Guides stores them as assets you point to from topics.

Good habits

  • Store media in a predictable folder structure.
  • Add meaningful alt text for accessibility.
  • Reuse a single image across topics with one reference.

Takeaway

Reference images centrally so updates propagate everywhere and accessibility stays consistent.
