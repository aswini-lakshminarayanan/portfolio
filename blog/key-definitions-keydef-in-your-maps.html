Key definitions (keydef) in your maps

AEM GuidesReuse

A key definition (keydef) assigns a value to a key in a map. Topics reference the key, and the map controls the value.

Common uses

  • Product names and version numbers.
  • External URLs.
  • Reusable link targets.

Takeaway

Keydefs put variable content under central control, so one edit updates every topic that uses it.
