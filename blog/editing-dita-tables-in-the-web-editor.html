Editing DITA tables in the Web Editor

AEM GuidesAuthoring

Tables are common in technical content, and the Web Editor makes them approachable.

Essentials

  • Insert a table and set the number of rows and columns.
  • Mark a header row so it repeats and styles correctly.
  • Add or remove rows and columns from the toolbar.
  • Merge cells for spanning headers where needed.

Takeaway

Build tables visually and let AEM Guides keep the DITA markup valid. No hand-editing required.
